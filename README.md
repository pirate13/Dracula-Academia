# Dracula Academia

**Dracula Academia** - студентський мобільний застосунок, розроблений на Flutter для Android. Застосунок має інтерфейс у готичному стилі та призначений для організації навчальних завдань, перегляду особистої інформації студента і відстеження корисних звичок.

## Функціонал

Застосунок складається з чотирьох основних екранів:

1. **Замок (Home)** - головна сторінка з навігацією між розділами та інформацією про навчальний прогрес.
2. **Книга проклять (Tasks / Deadlines)** - список навчальних завдань із можливістю додавання, редагування, видалення та позначення виконаних завдань. Дані зберігаються у Cloud Firestore.
3. **Паспорт безсмертного (Student ID / Profile)** - картка студента з особистими даними, які можна переглядати та редагувати. Інформація зберігається у Firebase.
4. **Ритуали виживання (Health & Focus)** - рекомендації щодо здоров'я під час роботи за комп'ютером і простий трекер корисних звичок.

Також реалізовано реєстрацію та авторизацію користувачів через Firebase Authentication.

## Робота з Firebase

Firebase використовується для збереження та отримання даних користувачів.

**Firebase Authentication** забезпечує реєстрацію та вхід за електронною поштою і паролем.

**Cloud Firestore** використовується для збереження профілю студента та навчальних завдань. Зміни в базі даних автоматично відображаються у застосунку.

**Firebase Storage** передбачений для завантаження фотографії студента.

Для кожного користувача дані зберігаються окремо відповідно до його UID.

## Встановлення та запуск

1. Клонувати репозиторій:

   ```bash
   git clone https://github.com/pirate13/Dracula-Academia.git
   ```

2. Відкрити проєкт в Android Studio.

3. Встановити залежності:

   ```bash
   flutter pub get
   ```

4. Налаштувати власний проєкт Firebase та виконати:

   ```bash
   flutterfire configure --platforms=android
   ```

5. У Firebase Console увімкнути Authentication, створити Cloud Firestore та налаштувати правила доступу з файлу `firestore.rules`. Для фотографій налаштувати Firebase Storage і правила з `storage.rules`.

6. Запустити Android-емулятор або підключити телефон.

7. Виконати команду:

   ```bash
   flutter run
   ```

## Структура даних

У Cloud Firestore використовуються дві основні колекції:

- `students` - особисті дані користувачів.
- `tasks` - навчальні завдання, дедлайни та статуси виконання.

Для ідентифікації користувачів використовується Firebase UID.

## Особливості інтерфейсу

Застосунок оформлений у стилі Dracula Academia з використанням темних кольорів, бордових акцентів та готичних елементів.

Для відображення навчальних завдань використовуються тематичні картки, а виконані завдання позначаються зображенням закритої труни.
